# Jomato Restaurant Analytics Dashboard

An interactive Streamlit dashboard built around the supplied
**JOMATO ASSIGNMENT(1).sql** and **Jomato.csv** files.

The dashboard presents restaurant data and reproduces the key
transformations and query outputs from the SQL assignment.

It does not use the unrelated "Synergizing Success" project title
or employee-engagement metrics.
